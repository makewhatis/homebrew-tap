# Rhapsody Homebrew tap

Homebrew tap for [Rhapsody](https://github.com/makewhatis/rhapsody) — the Rust parity port of Symphony.

```sh
brew install --cask makewhatis/tap/rhapsody
```

`Casks/rhapsody.rb` is generated from `desktop/scripts/render-cask.sh` in the
[rhapsody](https://github.com/makewhatis/rhapsody) repo and bumped automatically by its `release.yml`
on each published release.
